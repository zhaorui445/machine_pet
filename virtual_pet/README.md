# 虚拟宠物本地软件

这是运行在本机浏览器中的电子宠物界面，使用项目自己的 v6r5 PetLM 候选，不调用豆包、云端大模型 API 或训练服务。聊天、记忆和提醒保存在本机 SQLite 数据库。未加载本地权重时，程序会明确显示为离线演示。

真实电机、车轮、GPIO/串口控制和自主导航未接入。聊天中的移动问题只由安全状态机澄清，不会触发物理动作。仿真网关也与网页聊天隔离。

## 启动

在 VS Code 中打开 `virtual-pet.code-workspace`，在“运行和调试”选择“虚拟宠物：启动（本地 v6r5）”并按 F5。首次加载会校验冻结清单中的文件哈希，再加载基础模型和适配器；RTX 5060 等 CUDA 显卡可用于本地生成。

也可在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe .\virtual_pet\app.py --local-model
```

浏览器打开 <http://127.0.0.1:8765>。如果模型文件缺失或与冻结清单不一致，程序会拒绝启动本地模型，不会静默改用其他候选。`--data-dir` 可指定另一处 SQLite 数据目录；默认数据目录为 `virtual_pet/data`。

仅检查界面、记忆和提醒时，可不传 `--local-model`，进入离线演示模式：

```powershell
.\.venv\Scripts\python.exe .\virtual_pet\app.py
```

## 已接入能力

- 本地对话：冻结的 PetLM v6r5 基础权重、四个能力 LoRA 和统一路由；保护状态机先于生成执行。
- 记忆：只有明确添加或同意后才保存；可查看、修改和删除。默认不加入模型上下文，开启设置后最多提供最近 20 条。
- 提醒：在本机设置和触发；需要程序和页面保持运行，系统休眠或浏览器后台节流可能造成延迟。
- 语音：浏览器语音识别先转成文字，由用户检查后发送；识别服务可能把音频发给浏览器厂商。朗读由浏览器语音合成提供。
- 宠物动画：摸头、玩耍和休息只改变界面表现，不代表模型感受。

v6r5 内部验收中，保护应用严格通过 320/320；纯模型严格通过 0/320。因此本地模型仍属实验候选，回答可能错误；不要据此处理医疗、危险材料或现实移动任务。

## 数据边界

- HTTP 服务只监听 `127.0.0.1`，不应直接暴露到公网。
- 本地模型请求不会通过网络发送。浏览器语音识别是例外，启用时页面会询问本次会话的语音授权。
- 记忆和聊天 SQLite 数据库未加密，受本机文件权限保护。
- 删除一条记忆不会删除聊天记录中重复出现的文字；清空聊天不会删除记忆或提醒。
- `config.json` 不再配置或启用外部模型 API。旧配置值不会被加载。

## 测试

在本目录执行：

```powershell
..\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

集成测试使用临时 SQLite 数据库和模拟本地生成器，不加载真实模型、不调用网络或收费接口。语音输入需要在目标浏览器中由用户授权后手动验证。
